# devicebasedauth.org Project Status

**This file is the single source of truth for project status.** If another document disagrees
with it, this file wins and the other document is stale.

- **Last audited:** 2026-11-21
- **Production:** not deployed (owner steps in [docs/ops/deployment.md](docs/ops/deployment.md)).
- **Overall:** Service, verify library, browser SDK, CLI, samples and OIDC provider implemented and
  tested locally (`npm test`, `npm run test:samples`, `npm run test:e2e`). Prices approved by the owner
  (D6, D11, 2026-11-18). Open decisions D2, D7–D8 are implemented with the recommended defaults. The owner approved D9 (security email through Amazon SES, 200 µ$ per email) on 2026-11-21.
  Backlog B1–B4 (revocation webhooks, enrollment tokens, X.509 client certificates, shared replay
  cache) are done, B5 key attestation (Android, Apple App Attest, TPM 2.0 incl. EK activation for Linux) is done pending live checks on real devices, and S4 has Android and iOS samples (iOS awaiting a real-iPhone run); S9 lets devices recover from a withdrawn issuer key without re-enrolling (SDK v1.1.0); B7 additional gates (approvals, sign-in gates, periodic confirmation; G1–G9) are implemented, pending D13 prices and live Duo/Okta checks; L15 compacts records once their prepaid 13 months are over, which raised the issue price
  from 75 to its new floor of 85 µ$, so anything more it must prepay needs a price change.
  Design in [`todo/master_plan.md`](todo/master_plan.md); prices in [`docs/business/pricing.md`](docs/business/pricing.md).
