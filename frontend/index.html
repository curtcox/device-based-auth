Revocable, device-bound credentials you can read.

Enroll a browser, phone, laptop, server, script or AI agent. It keeps its own private key. devicebasedauth.org issues it a signed, plain-JSON list of exactly what it may do, on which site, at which times and in which places — and you can revoke it at any time.

Device-bound

The device generates its key pair and sends only the public key. Every request carries a fresh DPoP proof signed by that key, so a copied credential is useless.

Readable

A credential is a compact JWS whose middle part is plain JSON: device, sites, actions, time windows, places, networks and limits. The inspector shows any credential in plain English.

Revocable

Revoke one credential, a device, or everything at once. Online checks see it instantly; offline verifiers see it through signed status lists within about a minute plus their cache time.

Free to verify

Servers verify credentials offline with a zero-dependency library and cached public keys. Only optional online decisions (usage limits, step-up approval, instant revocation) are metered.

For developers and agents

Verify on your server

import { createVerifier } from '@devicebasedauth/verify';

const dba = createVerifier({ audience: 'example.com' });

export default {
  async fetch(request) {
    const result = await dba.verifyRequest(request, { action: 'example:notes:write' });
    if (!result.allow) return Response.json({ error: 'forbidden', reasons: result.reasons }, { status: result.status });
    return new Response(`Hello, ${result.account}`);
  }
};

Enroll a browser

import { DBA } from 'https://devicebasedauth.org/sdk/dba.js';

const dba = new DBA();
button.onclick = async () => {
  if (!await dba.ready()) {
    await dba.enroll({ aud: ['example.com'], grants: [{ actions: ['example:notes:write'] }] });
  }
  const response = await dba.fetch('https://example.com/api/notes', { method: 'POST', body: '…' });
};

Enroll a script, server or agent

dba enroll --aud example.com --action example:notes:write
dba curl https://example.com/api/notes
curl -H "Authorization: Bearer $(dba token --aud example.com)" https://example.com/api/notes

AI agents can request their own credentials through the MCP server and get an approval link for a human; grants can carry spend caps, usage limits and per-use approval.

What a credential says

{
  "aud": ["hashbin.org"],
  "device": { "name": "Laptop — Firefox", "kind": "browser" },
  "grants": [{
    "actions": ["hashbin:content:write"],
    "when": { "tz": "America/Chicago",
      "windows": [{ "days": ["mon","tue","wed","thu","fri"], "from": "08:00", "to": "18:00" }] },
    "where": { "source": "network", "countries": ["US"] },
    "limits": { "spend_usd_per_month": 5 }
  }]
}

“May "hashbin:content:write", on any resource, weekdays 08:00–18:00 (America/Chicago time), only from US (as seen from its network connection), spending at most $5.00 per month.”
