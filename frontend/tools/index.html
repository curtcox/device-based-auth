Developer tools

Everything here runs in your browser with the same @devicebasedauth/verify code that servers use. Nothing you paste is stored.

Credential inspector

Paste a credential to read its header, payload and grants in plain English, check its validity window, and ask the server about its signature and revocation.

Policy playground

Grants (or a credential) plus an action, a simulated time and a simulated location: see allow or deny, and why, grant by grant.

Grant builder

Pick actions from each site's catalog, add time windows, places, networks, limits and approval, and copy the JSON, a dba enroll command or a browser SDK snippet.

Request signer

Generate a throwaway key, and see the exact Authorization and DPoP headers (and a curl command) for any request.

Cost calculator

Devices, renewals, online decisions and reads → monthly cost, from the live prices.

Audience console

Register your site as an audience, publish its action catalog and its Sign in with devicebasedauth.org redirect URIs.

Machine-readable

  • /.well-known/jwks.json — the issuer's public keys.
  • /.well-known/openid-configuration — OpenID Connect discovery.
  • /openapi.json — the API, generated from the route table.
  • /llms.txt — a summary for language models and agents.
