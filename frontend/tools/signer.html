Request signer

Every request a device makes carries its credential and a fresh DPoP proof (RFC 9449) signed by the device key. This page makes a throwaway key in your browser and shows the exact headers for one request.

The key exists only in this tab and disappears when you leave. A real credential is bound to its own device's key (cnf.jkt), so a proof from this throwaway key will not verify against it — use this page to learn the format, or with the dba headers METHOD URL CLI command for real requests.
